# rafay.spec — QA Portfolio

A portfolio that runs a "live test run" on its owner: each section is an `it('should …')` test card that goes QUEUED → RUNNING → PASS as it scrolls into view.

**Live:** https://rafay-spec.netlify.app

## Sections
1. Hero (done)
2. Identity
3. Skills
4. Projects
5. LinkedIn posts
6. Automation (fails on purpose, retries, passes)
7. Contact + final report

One self-contained `index.html`, inline CSS/JS, no build tools. Images live in `/assets`.
